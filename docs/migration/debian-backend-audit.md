# Ryoku Debian Backend Migration Audit

## Origin

This project is a fork of:

https://github.com/Ryoku-dev/ryoku

This branch documents the architectural audit required to introduce
a Debian-based backend while preserving the Ryoku desktop architecture.

## Goal

Identify all Arch Linux specific dependencies:

- Package management
- Installer
- Release system
- Hardware management
- System configuration
- Build pipeline

No migration changes are performed in this phase.
